# Resume Templates

```
[NAME]
[Phone] | [Email] | [Location] | [LinkedIn] | [GitHub]

[2-line summary: role identity + key strength + quantified impact example]

TECHNICAL SKILLS
Languages:     [comma-separated]
Frameworks:    [comma-separated]
Infrastructure: [comma-separated]
Tools:          [comma-separated]

EXPERIENCE

[Company] | [Title]                                  [YYYY.MM—YYYY.MM]
- [Strongest achievement: built X using Y, achieving Z% impact]
- [Second strongest: optimized/championed/led X, result Y]
- [Technical depth: implemented X using Y to solve Z]
- [Collaboration or leadership: mentored/coached/cross-team X]

[Previous Company] | [Title]                          [YYYY.MM—YYYY.MM]

- [What you built and with what tech]
- [Impact or outcome]

[University] | [Degree]                               [YYYY.MM—YYYY.MM]
```

## Key Placement Rules

1. **Contact** + **Summary** — top 3 lines. If the reader doesn't immediately know who you are and what you do, the resume failed.
2. **Skills** — right below summary. Must be scannable in 2 seconds.
3. **Experience** — most recent first. Each role's first bullet should be the most impressive achievement.
4. **Recent role** gets 4-6 bullets. Each previous role gets 2-4. Oldest role gets 1-2.
5. **Projects** — only if you have space or if projects are more impressive than professional experience (career changers, fresh graduates).
6. **Education** — last section after first full-time job. No GPA, no coursework, no activities.

## Formatting Rules

- **Font**: Lato, Roboto, Calibri, or Arial. 10-11pt body, 14-16pt name.
- **Margins**: 0.5-0.75 inches all around.
- **File format**: PDF for human review / direct submission. DOCX for ATS systems.
- **PDF delivery**: ensure fonts are embedded, text is selectable (not scanned), no compression artifacts.
