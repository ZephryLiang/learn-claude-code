# Action Verbs for Engineering Resumes

## Leadership & Ownership

- Led — *Led the migration of 12 microservices from monolith*
- Drove — *Drove the adoption of type-safe patterns across the frontend org*
- Owned — *Owned the data ingestion pipeline serving 5 downstream teams*
- Spearheaded — *Spearheaded the incident response playbook, reducing MTTR by 40%*
- Directed — *Directed the architecture review process for 3 major platform initiatives*
- Orchestrated — *Orchestrated cross-team collaboration between 4 engineering teams*
- Chaired — *Chaired the weekly on-call review process*
- Established — *Established coding standards adopted by 15 engineers*
- Championed — *Championed the migration from REST to gRPC*
- Managed — *Managed the release cycle for a 50-service ecosystem*

## Building & Implementation

- Built — *Built a real-time streaming pipeline processing 10K events/sec*
- Designed — *Designed the multi-tenant authorization framework*
- Developed — *Developed an internal CLI tool adopted by 30+ engineers*
- Implemented — *Implemented a distributed rate limiter using Redis + Lua*
- Created — *Created a data migration framework reducing manual effort by 90%*
- Launched — *Launched the public API used by 200+ partner integrations*
- Deployed — *Deployed the service to production across 3 regions with blue/green*
- Constructed — *Constructed a fault-tolerant message queue consumer*
- Architected — *Architected the event-driven notification system*
- Authored — *Authored the engineering design doc for the caching layer*

## Optimization & Improvement

- Optimized — *Optimized SQL queries reducing report generation from 8min to 12s*
- Reduced — *Reduced cold start latency from 3s to 300ms through container optimization*
- Improved — *Improved test reliability by eliminating flaky tests (false-positive rate from 5% → 0.2%)*
- Accelerated — *Accelerated CI pipeline from 22min to 6min with parallelization*
- Streamlined — *Streamlined the deployment process from manual to one-click*
- Automated — *Automated the release process, eliminating 10 hours/week of manual work*
- Refactored — *Refactored 50K lines of legacy PHP to TypeScript*
- Modernized — *Modernized the build system from Webpack to Turbopack*
- Consolidated — *Consolidated 3 redundant services into 1 unified API*
- Simplified — *Simplified the configuration system from 2000 lines of YAML to 50*

## Analysis & Research

- Analyzed — *Analyzed query patterns to identify the top 5 performance bottlenecks*
- Evaluated — *Evaluated 3 vector database solutions (Pinecone, Weaviate, Milvus)*
- Assessed — *Assessed the security posture of 20 internal services*
- Audited — *Audited the data retention policy for GDPR compliance*
- Benchmarked — *Benchmarked the new architecture at 50K concurrent users*
- Modeled — *Modeled the cost implications of migrating to serverless architecture*
- Validated — *Validated the hypothesis through A/B testing with 100K users*
- Diagnosed — *Diagnosed the root cause of the production incident*
- Mapped — *Mapped the dependency graph for a 200-module codebase*
- Investigated — *Investigated memory leak patterns in the Node.js runtime*

## Mentoring & Communication

- Mentored — *Mentored 4 junior engineers through the onboarding process*
- Taught — *Taught internal workshops on distributed systems design*
- Coached — *Coached engineers on test-driven development practices*
- Documented — *Documented the system architecture and operational runbooks*
- Evangelized — *Evangelized TypeScript adoption across the frontend guild*
- Presented — *Presented the team's architecture proposal to VP-level stakeholders*
- Articulated — *Articulated technical tradeoffs to non-technical stakeholders*

- Orchestrated — *Orchestrated container deployments on Kubernetes across 5 environments*

- Monitored — *Monitored system health with Prometheus + Grafana dashboards*
- Migrated — *Migrated the database from MySQL to Aurora with zero downtime*
- Scaled — *Scaled the service from 100 to 100K concurrent users*
- Instrumented — *Instrumented application code with structured logging and tracing*

## Data & ML

- Fine-tuned — *Fine-tuned CodeLlama-13B with LoRA, raising SQL accuracy from 33% → 77%*

- Augmented — *Augmented the training dataset with synthetic data, improving recall by 15%*

- Experimented — *Experimented with 5 prompt engineering strategies to optimize accuracy*
- Explored — *Explored alternative caching strategies including Redis, Memcached, and in-memory*
- Piloted — *Piloted the new CI/CD platform with one team before org-wide rollout*

## When to Use Each Category

| Section | Preferred verb categories |
|---------|--------------------------|
| Recent roles | Built, Optimized, Led |
| Older roles | Built, Implemented |
| Side projects | Built, Created, Experimented |
| Leadership | Led, Drove, Orchestrated, Championed |
| Each role's first bullet | The strongest "Impact" verb available |
| Each role's second bullet | "What/how" verb (Built, Designed, Implemented) |
